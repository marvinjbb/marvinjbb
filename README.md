<p align="center">
  <b>The model is only one component.<br />
  The engineering is in the system around it.</b>

```text
                    User / System
                          |
                          v
                    API Boundary
                          |

                          |
                     +----+---------+
                     |              |

                   Model        Tools / Data
                     |              |
                     +------+-------+
                            |
```
